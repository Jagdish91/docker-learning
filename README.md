This repo contains small, focused examples that teach Docker concepts: building images, running containers, mounting volumes, networking, and pushing images to registries. Each example is designed to be easy to follow and reproducible.

What is a container (short)

A container packages your application together with its runtime and minimal dependencies so it runs the same way on any machine that supports containers. Containers are smaller and faster than full virtual machines because they share the host kernel and include only what your app needs.

Why use Docker

Reproducible environments

Faster startup and smaller footprint than VMs

Easy image sharing via registries (Docker Hub, Quay, etc.)
